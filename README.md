# Weather Outfit Platform

This project demonstrates a complete containerized application lifecycle including build automation, orchestration, deployment, networking, and CI/CD using Docker and Maven.

## Tech Stack
- Frontend: React
- Backend: Spring Boot
- Build Tool: Maven
- Containerization: Docker
- Orchestration: Docker Compose
- CI/CD: GitHub Actions
- Database: MySQL
- Cache: Redis
- Reverse Proxy: Nginx

## Running Locally
Run `docker-compose up --build` to start the cluster.
